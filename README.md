# ভোটার সার্চ — ফোনের পেজ (GitHub Pages)

ফোনে খোলার মতো ছোট পেজ। সার্চের লাইভ লিংকটা এখানে এমবেড করা থাকে।

## গোপনীয়তা — key কোথায় থাকে

- **key এই রিপোতে কোথাও নেই।** `index.html` বা `current.json` — কোনো ফাইলেই key লেখা নেই।
- key শুধু **আপনার ফোনের ব্রাউজারে** থাকে (localStorage)। প্রথমবার চ্যাটের লিংক থেকে খুললে বা ফর্মে লিখলে একবার সংরক্ষণ হয়, তারপর আর চাইবে না।
- `current.json`-এ শুধু টানেলের ঠিকানা (URL) থাকে — key ছাড়া ওই ঠিকানা দিয়ে কিছুই খোলে না (403 আসে)।

## অটো-আপডেট কীভাবে হয়

লিংক ২৪ ঘণ্টায় মেয়াদ শেষ হয়। `renew-link.sh` (অটো-রিনিউ স্ক্রিপ্ট) নতুন টানেল বানালেই `current.json` আপডেট করে দেয় — নতুন URL লিখে দেয়। এই ফাইলটা GitHub Pages-এ পাবলিশ হলেই ফোনের পেজটা নিজে থেকে নতুন লিংক ধরবে, কিছু করতে হবে না।

## পাবলিশ করা

এই ফোল্ডারটা GitHub রিপোতে পুশ করে Pages চালু করলেই লাইভ হবে (Settings → Pages → Branch: main)। `current.json` আপডেট হলে পুশ করলেই নতুন লিংক চলে যাবে।
